# ⚡ Voltify – Electricity Bill Optimizer

## 📌 Description
Voltify is a smart electricity bill optimization web application built using Streamlit.  
It helps users track their daily electricity usage, estimate monthly bills, and identify high energy-consuming appliances.

The application provides clear insights and suggestions to help users reduce electricity costs and improve energy efficiency in a simple and interactive way.

---

## 🚀 Features

- 📊 Calculates daily electricity consumption
- 💸 Estimates monthly electricity bill
- ⚡ Supports multiple states with different electricity pricing
- ➕ Add custom appliances with wattage and usage time
- 📈 Visual breakdown of appliance-wise energy usage
- 🔍 Identifies highest energy-consuming appliance
- 💡 Provides smart suggestions to reduce electricity usage
- 💰 Displays potential monthly savings
- ⭐ Generates an energy efficiency score

## 💡 How It Works

- Users input the number of hours each appliance is used daily
- Energy consumption is calculated using:

  Power (W) × Time (hours) ÷ 1000 = Units (kWh)

- Based on selected state electricity cost:
  - Daily bill is calculated
  - Monthly bill is estimated

- The system analyzes:
  - Appliance usage
  - Highest energy consumer
  - Possible savings

- Smart insights are generated to help optimize electricity usage
